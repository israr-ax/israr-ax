# About

I am a **Backend Developer and Computer Science professional** focused on designing reliable, secure, and scalable software systems. My engineering work centers on **Python, Django, Django REST Framework, PostgreSQL, Redis, WebSockets, and API architecture**, with practical experience building role-based platforms and real-time applications.

My primary strength is backend engineering: translating product requirements into maintainable architectures, designing normalized database schemas, implementing secure authentication and authorization, and building APIs that can support real-world application workflows.

I also work across the full stack with **React, JavaScript, FastAPI, and SQL**, allowing me to understand and integrate complete product flows rather than treating backend and frontend systems as isolated components.

My engineering interests increasingly extend toward **Artificial Intelligence, Machine Learning, and scalable AI systems**, with a focus on understanding how intelligent capabilities can be integrated into production software.

- **Security** — JWT authentication, authorization, protected routes, role-based access control

- **Real-Time Systems** — Django Channels, Redis, WebSockets, live application workflows
- **Product Engineering** — Building software around real user workflows and business requirements
- **AI/ML Direction** — Exploring AI, Machine Learning, and scalable AI-powered systems
